## Proof, not adjectives

- **An app in the App Store.** [The BitBinder](https://apps.apple.com/us/app/the-bitbinder/id6756085897) passed Apple review and ships to real users — SwiftData with CloudKit sync, on-device speech recognition, Vision-based text import.

## How I work

I build for problems I actually have. The BitBinder exists because comics keep their material scattered across Notes files and voice memos. The Trip Handler exists because organizing a group trip over a group chat is chaos. Knowing the workflow first is why the tools fit it.

I ship the unglamorous parts too — auth, permissions, payments, offline sync, App Store review — and I prefer on-device processing to sending user data to a server when the platform lets me.
