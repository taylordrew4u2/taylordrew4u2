## Featured work

### [The Bit Binder](https://github.com/taylordrew4u2/The-Bit-Binder)

Native iOS app for stand-up comedians to capture, organize, record, transcribe,
and refine material. Built with SwiftUI, SwiftData, and CloudKit and
[available on the App Store](https://apps.apple.com/us/app/the-bitbinder/id6756085897).

### [Showrunner](https://github.com/taylordrew4u2/Showrunner-ICanRunAShow)

Production tool used during live comedy shows. It builds lineups, imports
schedules from photos with AI, and runs a full-screen show mode with cue timers
and walk-on music. Built with React and TypeScript.

### [Role-Call](https://github.com/taylordrew4u2/Role-Call)

End-to-end film-production planner for crew roles, cast, scripts, shot lists,
and schedules. Built with Next.js, TypeScript, Clerk, and Drizzle.

### [Bill Spilt](https://github.com/taylordrew4u2/Bill-Spilt)

A straightforward full-stack tool for splitting household bills and keeping
shared expenses organized.

### [The Trip Handler](https://github.com/taylordrew4u2/the-trip-handler)

Group-trip organizer with private invites, applications and approvals, shared
itineraries, expense tracking, and Stripe payments.
